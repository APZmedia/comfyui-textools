ComfyUI-textools Emoji Font Information
========================================

This directory contains emoji fonts for ComfyUI-textools.

Expected files:
- NotoColorEmoji.ttf (Google's Noto Color Emoji font)

The emoji support system will:
1. First try to use bundled fonts from this directory
2. Fall back to system emoji fonts if bundled fonts are not available
3. Use default fonts as last resort

This ensures consistent emoji rendering across all platforms.
